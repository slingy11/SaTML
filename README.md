# From Weight Collisions to Behavior: reproduction package

This anonymous package supports the manuscript in `paper/` (single-file version:
`paper/submission/main.tex`). GPU outputs and the source snapshots that produced them are
kept unchanged under `kaggle/*/output_v*`; derived CPU analysis is regenerated by the
scripts below.

## 1. Tables and figures from stored outputs (no GPU, minutes)

Python 3.10+ with NumPy, pandas and Matplotlib. From the package root:

```sh
python paper/build_evidence.py        # honest W8A8 study, earlier constructions, geometry
python paper/build_feasibility.py     # Table I (capacity), Table III (whole-UNet), Table V (audit)
python paper/build_d1.py              # Table IV (optimal attack) and figure summary
python paper/make_figures.py          # Figures 1-2 (Figure 1 needs paper/data/coord_hist.npz)
cd paper && tectonic main.tex         # or pdflatex + bibtex; see note below
```

Every builder verifies the SHA-256 of each result file against the run's
`run_manifest.json` before using it. Bootstrap intervals are deterministic at their
recorded seeds.

## 2. Feasibility analysis and certificate (CPU, about 1 hour; GPU, minutes)

`experiments/d0_feasibility.py` computes, for every edited key/value tensor and each
recipe (W8A8 SmoothQuant, INT8, INT4 g128, NF4 g64), the exact deployed-collision box
(`lib/collision.py`), the optimal attack in the embedding Gram metric, its Frank-Wolfe
certificate, passive survival of the honest edit, and the image-free audit statistic.
It needs the public SD-1.5 weights, the pinned UCE `data/` folder and the stored
calibration statistics:

```sh
SD_DIR=<sd-1.5 snapshot> UCE_DATA=<uce>/data STATS=kaggle/aq-satml-calibration/output_v1/outputs/act_stats.npz \
OUT=outputs/d0 python experiments/d0_feasibility.py
SD_DIR=<sd-1.5 snapshot> python paper/coord_hist.py   # per-coordinate histograms for Figure 1
python tests/run_all.py                                # includes exact-collision tests
```

The reported numbers come from the GPU run (4000 iterations) stored in
`kaggle/aq-satml-optattack-{style,nudity}/output_v1/outputs/d0_*.csv`.

## 3. Behavioral runs (GPU)

The snapshot folders under `kaggle/` contain the executed library and experiment
sources, outputs and manifests. Obtain UCE at revision
`7c724d9d7d19190e9bd33fe62fb656f1df87cd8e`, set `UCE_DIR`, and install the versions
recorded in each manifest (PyTorch 2.4.1+cu121, Diffusers 0.34.0, Transformers 4.49.0,
NudeNet 3.4.2; Tesla T4). Use a fresh output directory.

| Result | Snapshot | Entry point |
|---|---|---|
| Honest W8A8 style / nudity (Table II) | `aq-satml-power-{style,nudity}` | `a2`, `a4`, `a7` |
| Whole-UNet W8A8 control (Table III) | `aq-satml-alllinear-audit` | `c2_alllinear_audit.py` |
| Optimal attack, 4-bit passive (Tables I, IV, V) | `aq-satml-optattack-{style,nudity}` | `d0_feasibility.py` then `d1_opt_behavior.py` |
| Earlier constructions (Appendix D) | `aq-satml-fixedpoint-gate`, `aq-satml-matched-*` | `a8`, `a9` |

`d1_opt_behavior.py` asserts that every crafted checkpoint is an exact deployed
collision before generating images. Crafted checkpoints are regenerated
deterministically by `d0` and are not distributed; their SHA-256 digests are in
`d1_*_checkpoint_sha256.json`.

## Notes

- All reported deployments use SmoothQuant exponent 0.5. Earlier constructions crafted
  at 0.75 are confined to Appendix D (see Appendix F of the paper).
- The 192 cells per condition are 12 seeds crossed with 16 selected prompts, not
  independent prompt samples.
- Excluded: generated images, base-model and edited weights, upstream datasets,
  credentials and provider metadata. `paper/data/prompts.json` lists the selected
  prompts and source digests. Third-party models, data and code keep their licenses.
- LaTeX: `tectonic` (XeTeX) uses TeX Gyre Termes; pdfLaTeX builds use `mathptmx`.
